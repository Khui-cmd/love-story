# 花束みたいな日々 — 我们的恋爱日常

一个献给两个人的纪念网站,灵感来自电影《花束般的恋爱》。单文件、纯静态、无需服务器,打开即用。

整体以白色为主、粉色点缀的低饱和暖色调,带胶片颗粒质感;登录页采用暖米色调 + 拨号式密码键盘 + 拍立得相册。

## ✨ 功能

- **双模式浏览**
  - 🗺️ 中国地图模式:省份 → 城市逐级下钻(离线 SVG 地图,不依赖任何外部库)
  - ⏳ 时间线模式:按日期串起你们的故事
- **回忆记录**
  - 在地图上双击城市即可添加回忆,每条回忆可上传多张照片(不限数量,本地压缩)
  - 回忆图标(爱心)跟随城市位置,数量越多图标越大
  - 有照片的地点在地图上显示为「拍立得」照片图钉,并每隔几秒随机切换一张回忆照片
  - 回忆面板自动居中在地图上
- **登录页**
  - 拨号式数字密码键盘(可切换为普通键盘输入)
  - 可自定义头像,右侧拍立得相册跟随鼠标 3D 晃动
- **管理后台**
  - 增删改回忆、上传照片
  - 自定义:纪念日、双方名字、标题、副标题、登录头像、访问密码
  - 右上角自定义纪念日卡片:可添加多个纪念日(名称 + 日期),自动显示「还有 X 天 / 已 X 天」
- **数据本地化**
  - 全部内容保存在浏览器 localStorage,照片压缩为 base64 内嵌

## 🚀 使用方法

1. 直接双击打开 `index.html`(用 Chrome / Edge 等现代浏览器)。
2. 首次使用会引导你**设置访问密码**(4–8 位数字)。
3. 进入后点击右上角「管理」添加回忆、上传照片、改标题等。
4. 数据存在浏览器本地,**清除浏览器缓存会导致数据丢失**。

> 说明:密码为纯前端校验,目的是「挡住路人」而非银行级安全;照片与文字都存在你自己的浏览器里,不会上传到任何服务器。

## ☁️ 在线保存与账号(可选)

默认是纯本地模式(数据在浏览器 localStorage)。想**在不同设备上登录同一账号、看到并编辑同一份内容**,启用后端即可:

1. 安装 [Node.js](https://nodejs.org/)(18 或更新)。
2. 复制 `config.example.json` 为 `config.json`,改掉账号密码:
   ```json
   { "port": 3000, "adminUser": "admin", "adminPass": "你的密码" }
   ```
3. 启动:`node server.js`,浏览器打开 `http://localhost:3000`。
4. 打开 `index.html`,把顶部 `const CLOUD` 里的 `enabled` 改成 `true`,`baseUrl` 留空 `""`(同源)。
5. 点右上角「⚙ 管理」→ 用 `config.json` 里的账号密码登录 → 改内容即自动存到服务器。

**部署到公网**(让两台设备都能访问):把这个项目整个放到一台能公网访问的机器 / 云服务器 / 托管平台(如 Render、Railway、任意 VPS),跑 `node server.js` 即可。同一个账号在任何设备登录,读写的都是服务器上同一份 `data.json`。

> 数据文件(`data.json` / `users.json` / `uploads/`)已加入 `.gitignore`,不会提交到 git。

**账号管理后台(独立页面,普通用户不可见)**:浏览器打开 `admin.html`(或部署后的 `你的域名/admin.html`),用管理员账号登录即可增删账号、重置密码。该页面不链接到主站任何地方,只有管理员知道地址。

## 📁 文件结构

```
love-story/
├── index.html       # 全部页面 / 样式 / 逻辑(单文件)
├── admin.html       # 账号管理后台(独立页面,仅管理员)
├── china-geo.js     # 离线中国地图 GeoJSON(省 / 市边界)
├── server.js        # 后端(账号 + 数据 + 照片,零依赖,可选)
├── config.example.json  # 后端配置模板
└── README.md
```

## 🛠 技术栈

- 原生 HTML / CSS / JavaScript,无构建步骤、无框架
- 自定义 SVG 地图投影(中国范围自适应 + 省份自动缩放)
- localStorage 持久化、Canvas 图片压缩、FileReader 上传
- 密码哈希(djb2 变体)仅用于本地比对

## 📝 自定义

所有文案、日期、名字、照片、地图点都在「管理后台 → 设置 / 回忆事件」里改,无需碰代码。
